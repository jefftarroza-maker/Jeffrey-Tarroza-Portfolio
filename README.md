# Jeffrey Tarroza - K-5 Educator Portfolio

Welcome to the official web portfolio for **Jeff Tarroza**, a certified K-5 Elementary Educator specializing in foundational literacy, early STEM integration, and student-centered learning.

## 🌟 Features
- **Responsive Modern Design**: Built with clean semantic HTML5, custom CSS design system, and Google Fonts (`Outfit` & `Inter`).
- **Warm & Inspiring Aesthetics**: Soft Terracotta and Sage Green color palette with dark/light theme support.
- **Interactive Sections**: Hero Showcase, Core Teaching Philosophy, Experience & Education Timeline, Classroom Project Spotlight, and Contact Form.
- **Live In-Browser Editor**: Built-in quick editor allowing real-time updates to bio, contact info, and experience details.

## 🚀 Quick Start
Open `index.html` in any modern web browser to view the portfolio locally.
